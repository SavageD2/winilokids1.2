# Backend Winilo Kids

Le guide principal de lancement du projet est dans [README.md](/home/Savage/git/win1.2/README.md).

## Commandes backend les plus utiles

```bash
npm install
npm run prisma:generate
npm run prisma:migrate:deploy
npm run seed:admin
npm run seed:demo
npm run start:dev
npm run build
npm test -- --watch=false
```

## URLs backend

- API : `http://localhost:3000/api`
- healthcheck : `http://localhost:3000/api/health`
- Swagger : `http://localhost:3000/docs`
