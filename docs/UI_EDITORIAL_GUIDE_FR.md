# Guide éditorial UI FR

Date : 26 mars 2026

## Objectif

Ce guide pose une base simple pour harmoniser les textes de l'interface Winilo Kids avant la généralisation FR / EN.

## Principes

- Écrire en français clair, rassurant et direct.
- Privilégier une voix humaine, simple et utile.
- Éviter le jargon interne et les formulations administratives trop froides.
- Préférer des phrases courtes dans les titres, boutons et aides contextuelles.

## Casse

- Titres de page : casse phrase.
- Labels de champ : casse phrase.
- Boutons : verbe d'action clair, casse phrase.
- Messages de succès et d'erreur : phrase complète, casse phrase.
- Acronymes établis : `FAQ`, `JWT`, `Google Calendar`.

## Ponctuation

- Utiliser les accents partout où ils sont attendus.
- Utiliser des apostrophes cohérentes.
- Éviter les points d'exclamation sauf cas exceptionnel.
- Éviter les ellipses inutiles dans les libellés fixes.

## Ton

- Chaleureux, rassurant, non infantilisant.
- Orienté action pour les boutons.
- Orienté solution pour les messages d'erreur.
- Orienté accompagnement pour les aides et explications.

## Terminologie produit

- `atelier`
- `réservation`
- `inscription`
- `compte parent`
- `espace administrateur`
- `brouillon`
- `publié`
- `message de contact`
- `note interne`
- `apparence`
- `langue`

## Verbes recommandés

- `Se connecter`
- `Se déconnecter`
- `Créer`
- `Mettre à jour`
- `Enregistrer`
- `Supprimer`
- `Continuer`
- `Annuler`

## Patterns recommandés

- Succès : `Profil mis à jour avec succès.`
- Erreur action : `Impossible de charger les ateliers pour le moment.`
- Aide champ : `Utilise seulement des lettres minuscules, chiffres et tirets.`
- État vide : `Aucun atelier ne correspond à la recherche actuelle.`

## Points de vigilance

- Ne pas mélanger `réservation` et `inscription` sans raison.
- Ne pas alterner `thème`, `apparence` et `mode` dans l'UI française : préférer `apparence`.
- Ne pas alterner `téléphone` et `tél.` dans les labels : préférer `Téléphone`.
- Ne pas réutiliser les messages backend anglais tels quels dans l'UI.
